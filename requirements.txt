# ── PEFT + its hard requirement ───────────────────────────────────────────
# PEFT 0.19's LoRA dispatcher imports torchao and refuses to load if the
# installed version is < 0.16.0, even when we are not actually using torchao
# quantization. Colab pre-installs torchao 0.10.x, so we MUST upgrade it.
peft>=0.19.0
torchao>=0.16.0; sys_platform == 'linux'

# ── Optional CUDA fast-path kernels (Linux only — skipped on macOS) ───────
# Pure-python wheel: safe to install everywhere on Linux.
flash-linear-attention; sys_platform == 'linux'

# ── gpt-oss (openai/gpt-oss-20b) ──────────────────────────────────────────
# The released checkpoint ships MXFP4-quantised experts. We load with
# transformers' Mxfp4Config(dequantize=True) → bf16 (~40GB, needs an 80GB GPU),
# which requires the MXFP4 dequant path bundled in recent transformers (already
# pinned to git HEAD above) plus triton on the GPU host. LoRA on its fused
# expert tensors uses peft>=0.17 `target_parameters` (already satisfied by the
# peft>=0.19 pin above). No extra package is required beyond a triton install on
# the (Linux/CUDA) training host.
triton; sys_platform == 'linux'
